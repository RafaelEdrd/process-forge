# Decisões de publicação

O código de `showcase/engine` é JavaScript entregue ao navegador e pode ser inspecionado; não representa uma barreira de proteção de propriedade intelectual.

O motor de referência executa um subconjunto restrito de operadores sem conectores, sem acesso a dados remotos e sem credenciais. Os componentes administrativos e a persistência comercial permanecem fora deste repositório.
