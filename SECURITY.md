# Segurança e limites

Esta é uma **implementação demonstrativa**, não um serviço público com backend. Arquivos de `showcase/` são entregues integralmente ao navegador e seus algoritmos são visíveis ao visitante.

- Não forneça dados pessoais reais, credenciais ou informações comerciais sensíveis na demonstração.
- O `reference/` não autentica usuários e não representa uma API operacional.
- Nenhum arquivo `.env`, banco de dados ou motor privado deve ser copiado para este repositório.
- Execute um servidor local em `127.0.0.1`; não habilite acesso externo sem uma revisão de segurança.
- Vulnerabilidades relevantes podem ser comunicadas pelo canal de contato em https://rafaelanalyst.com.br/contato/; não inclua segredos em relatórios públicos.
